# MacVPN and WinVPN 2.0.1 – release notes

Released 2026-10-26 (`v2.0.1`). A maintenance release on top of [2.0.0](2.0.0.md).

## English

### Both apps

- **Reconnect Automatically** never brings back a connection that a control API lease started. Such a connection stays down after it drops, also across sleep; it becomes reconnectable again once you connect it yourself. A connection you started and a lease later joined keeps your setting.
- A connection row no longer shows "Missing tool" for a moment before the first setup check; it shows its type until the check has run.

### WinVPN (Windows)

- No leftover "Native Windows VPNs come in a later version" text anywhere: L2TP/IPsec, IKEv2 and SSTP ship since 2.0.0.
- An OpenVPN Community whose version WinVPN cannot read now counts as **Not ready**: System Status shows "!" and opens at launch. An OpenVPN that is simply not installed is still optional.
- The OpenVPN and WireGuard rows of System Status each have their own **Update** button.

No root layer change on macOS (it stays 9).

## Magyar

### Mindkét app

- Az **Automatikus újracsatlakozás** soha nem hozza vissza azt a kapcsolatot, amelyet a vezérlő API egy bérlettel (lease) indított. Ha egy ilyen kapcsolat megszakad, bontva marad, alvás után is; újra csak akkor csatlakozik magától, ha egyszer te magad csatlakoztatod. Az általad indított kapcsolatra, amelyhez később egy bérlet csatlakozott, a te beállításod érvényes.
- A kapcsolat sora az első rendszerellenőrzés előtt már nem írja ki egy pillanatra, hogy „Hiányzó eszköz”; az ellenőrzésig csak a típusa látszik.

### WinVPN (Windows)

- Sehol nem maradt a „Natív Windows VPN-ek egy későbbi verzióban” szöveg: az L2TP/IPsec, az IKEv2 és az SSTP a 2.0.0 óta működik.
- Ha a WinVPN nem tudja kiolvasni az OpenVPN Community verzióját, az mostantól **Nem használható**: a Rendszerállapot „!” jelet kap, és induláskor megnyílik. A csak egyszerűen nem telepített OpenVPN továbbra is opcionális.
- A Rendszerállapotban az OpenVPN és a WireGuard sorának saját **Frissítés** gombja van.

A macOS-es root-réteg nem változik (marad a 9-es).
