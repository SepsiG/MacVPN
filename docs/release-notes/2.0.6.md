# MacVPN and WinVPN 2.0.6 – release notes

Released 2026-10-29 (`v2.0.6`). A small release on top of [2.0.5](2.0.5.md).

## English

### Both apps

- **WireGuard keys in the editor.** Under a WireGuard configuration there is a new **Interface keys** box:
  - **Generate Key Pair** creates a new private key, the same way `wg genkey` does. If the connection already has a key, it asks first, because the other side must then get the new public key.
  - **Public key** is shown read-only, with **Copy**, and follows every change of the private key. A bad private key shows "Invalid private key".
  - **Private key** is masked, with **Show** and **Copy**. It is copied like a password: clipboard managers don't keep it and it is removed from the clipboard after a minute.
  - When the configuration has one peer, its **preshared key** can be generated, shown and copied the same way.
  - Keys are generated by the app itself, never by the web view, and never written to a log.
  - Each WireGuard connection has its own key pair; generating a key changes only the connection you are editing.

No root layer change on macOS (it stays 11).

## Magyar

### Mindkét app

- **WireGuard-kulcsok a szerkesztőben.** A WireGuard-konfiguráció alatt új **Interface-kulcsok** rész van:
  - A **Kulcspár generálása** új privát kulcsot készít, ugyanúgy, mint a `wg genkey`. Ha a kapcsolatnak már van kulcsa, előbb rákérdez, mert a másik oldalon is be kell állítani az új publikus kulcsot.
  - A **Publikus kulcs** csak olvasható, **Másolás** gombbal, és követi a privát kulcs minden változását. Hibás privát kulcsnál „Érvénytelen privát kulcs” látszik.
  - A **Privát kulcs** rejtett, **Megjelenítés** és **Másolás** gombbal. Úgy másolódik, mint egy jelszó: a vágólapkezelők nem őrzik meg, és egy perc múlva törlődik a vágólapról.
  - Ha a konfigurációban egy társ (peer) van, az **előmegosztott kulcsa** ugyanígy generálható, megjeleníthető és másolható.
  - A kulcsokat maga az app készíti, soha nem a webes felület, és naplóba sem kerülnek.
  - Minden WireGuard-kapcsolatnak saját kulcspárja van; a generálás csak a szerkesztett kapcsolatot érinti.

A macOS-es root-réteg nem változik (marad a 11-es).
