# MacVPN and WinVPN 2.0.7 – release notes

Released 2026-10-30 (`v2.0.7`). On top of [2.0.6](2.0.6.md).

**macOS: the root layer changes (11 → 12).** After the update, System Status shows "Update required (11 → 12)"; click **Authorize** once and enter your admin password. Until you do, the root-based kinds are greyed out.

## English

### Both apps

- **Secrets in the config are hidden.** In the connection editor, the secret parts of a config are masked: private keys, OpenVPN key and password blocks, `tls-auth`/`tls-crypt`, and a strongSwan `secrets` section. Tick **Show secrets** to see and edit them; a hidden config can never be saved with the mask in it.
- **Certificate details.** The editor lists the certificates of a connection: subject, issuer, validity, key type, serial and SHA-256 fingerprint, with copy buttons. A certificate that expires within 30 days, or has expired, is flagged in the editor and on the connection's row.
- **Secret fields.** A password you are typing can be shown, the remove buttons say what they remove, the pre-shared key has one name everywhere ("Shared secret (PSK)"), the private key password appears only when the key needs one, and a password-protected PKCS#12 is asked for when connecting.
- **Export Without Keys** keeps the shared `tls-auth` / `tls-crypt` key, so the copy can connect; personal keys are still removed.

### MacVPN (macOS)

- **IKEv2 client certificates.** **Import Client Certificate…** takes a PKCS#12 file or a PEM certificate and key. The key is kept in the vault and placed where strongSwan needs it at connect; no files have to be copied by hand.
- **Fixed:** an IKEv2 connection that signs with an encrypted private key can now be given its password, in the editor or when connecting.

### WinVPN (Windows)

- IKEv2 with a certificate uses the computer certificate from Windows' store; the editor says how to import it.

## Magyar

**macOS: a root-réteg változik (11 → 12).** A frissítés után a Rendszerállapot ezt mutatja: „Frissítés szükséges (11 → 12)”. Kattints egyszer az **Engedélyezés** gombra, és add meg az admin jelszót. Addig a root-réteget használó kapcsolattípusok szürkék.

### Mindkét app

- **A config titkai rejtve vannak.** A kapcsolatszerkesztőben a config titkos részei el vannak takarva: a privát kulcsok, az OpenVPN kulcs- és jelszóblokkjai, a `tls-auth`/`tls-crypt`, és a strongSwan `secrets` része. A **Titkok megjelenítése** bejelölésével láthatod és szerkesztheted őket; rejtett állapotban a config soha nem menthető el a takarással együtt.
- **Tanúsítványadatok.** A szerkesztő felsorolja a kapcsolat tanúsítványait: tulajdonos, kiadó, érvényesség, kulcstípus, sorozatszám és SHA-256 ujjlenyomat, másolás gombokkal. A 30 napon belül lejáró vagy már lejárt tanúsítványt a szerkesztő és a kapcsolat sora is jelzi.
- **Titokmezők.** A gépelés alatt álló jelszó megjeleníthető, az eltávolítás gombok megmondják, mit törölnek, az előre megosztott kulcsnak mindenhol egy neve van („Közös kulcs (PSK)”), a privát kulcs jelszava csak akkor látszik, ha a kulcsnak kell, és a jelszóval védett PKCS#12 jelszavát csatlakozáskor kéri.
- Az **Exportálás kulcsok nélkül** megtartja a közös `tls-auth` / `tls-crypt` kulcsot, így a másolat tud csatlakozni; a személyes kulcsokat továbbra is eltávolítja.

### MacVPN (macOS)

- **IKEv2 klienstanúsítványok.** A **Klienstanúsítvány importálása…** PKCS#12 fájlt vagy PEM tanúsítványt és kulcsot fogad. A kulcs a széfbe kerül, és csatlakozáskor oda kerül, ahol a strongSwannak kell; semmit nem kell kézzel másolni.
- **Javítva:** a titkosított privát kulccsal aláíró IKEv2-kapcsolatnak most már megadható a kulcs jelszava, a szerkesztőben vagy csatlakozáskor.

### WinVPN (Windows)

- A tanúsítványos IKEv2 a Windows tanúsítványtárában lévő számítógép-tanúsítványt használja; a szerkesztő leírja, hogyan importáld.
