# MacVPN, WinVPN and LinVPN 2.1.1 – release notes

Released 2026-10-30 (`v2.1.1`). A small release on top of [2.1.0](2.1.0.md). MacVPN and LinVPN are unchanged apart from the version; the root layer stays 12.

## English

### WinVPN (Windows)

- **Fixed: updating OpenVPN from System Status.** When WinVPN runs under a standard user account and an administrator's password confirms the update, the installer could not read the downloaded OpenVPN package and wrongly reported that it was "not signed by OpenVPN Inc.". The package is now handed to the administrator step readably (it is still checked there, signature and all), and a failure to read it gets its own message.
- **Clearer IKEv2 sign-in error.** Windows reports error 13801 both for refused credentials and when it does not trust the server's certificate. The message now names both causes and points to **Trust This CA in Windows…** in the editor; the password is still asked for once more.

### LinVPN (Linux)

- The documentation now states the real minimum: NetworkManager 1.54.3 (Ubuntu 26.04).

## Magyar

### WinVPN (Windows)

- **Javítva: az OpenVPN frissítése a Rendszerállapotból.** Ha a WinVPN normál felhasználói fiókkal fut, és a frissítést egy rendszergazda jelszava hagyja jóvá, a telepítő nem tudta olvasni a letöltött OpenVPN-csomagot, és tévesen azt írta, hogy „nem az OpenVPN Inc. írta alá”. A csomagot a WinVPN most olvashatóan adja át a rendszergazdai lépésnek (ott továbbra is ellenőrzi, az aláírással együtt), és ha mégsem olvasható, arra külön üzenet jön.
- **Érthetőbb IKEv2-bejelentkezési hiba.** A Windows a 13801-es hibát akkor is adja, ha a hitelesítő adatokat utasítja el a szerver, és akkor is, ha nem bízik a szerver tanúsítványában. Az üzenet most mindkét okot megnevezi, és a szerkesztő **A CA megbízhatóvá tétele a Windowsban…** gombjára mutat; a jelszót továbbra is újra kéri.

### LinVPN (Linux)

- A dokumentáció most a valódi minimumot írja: NetworkManager 1.54.3 (Ubuntu 26.04).
