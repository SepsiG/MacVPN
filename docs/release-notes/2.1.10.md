# MacVPN, WinVPN and LinVPN 2.1.10 – release notes

Released 2026-11-05 (`v2.1.10`). A fix on top of [2.1.9](2.1.9.md). **MacVPN: root layer 16** (WinVPN and LinVPN: no change).

## English

- **The VPN's DNS with OpenVPN 2.7, for real (MacVPN, root layer 16):** the 2.1.9 fix for OpenVPN 2.7's DNS step lives in the root layer, but 2.1.9 did not raise the root layer's version, so Macs kept the 2.1.8 root layer and the VPN's DNS still did not take effect (`dns up command exited with status 127`, "the VPN sent no DNS"). Internet names kept working through the local network's DNS. 2.1.10 ships the fixed root layer: after the update, **System Status** shows **Update required (15 → 16)**: click **Authorize** and enter the admin password once (active VPN connections are disconnected first).

## Magyar

- **A VPN DNS-e OpenVPN 2.7-tel, most már valóban (MacVPN, 16-os root réteg):** a 2.1.9 javítása az OpenVPN 2.7 DNS-lépéséhez a root rétegben van, de a 2.1.9 nem emelte a root réteg verzióját, így a Mac-eken a 2.1.8-as root réteg maradt, és a VPN DNS-e továbbra sem lépett életbe (`dns up command exited with status 127`, „a VPN nem küldött DNS-t”). Az internetes nevek a helyi hálózat DNS-ével működtek. A 2.1.10 a javított root réteget hozza: a frissítés után a **Rendszerállapot** **Frissítés szükséges (15 → 16)** sort mutat: kattints az **Engedélyezés** gombra, és add meg egyszer az admin jelszót (az aktív VPN-kapcsolatok előbb bomlanak).
