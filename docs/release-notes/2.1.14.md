# MacVPN, WinVPN and LinVPN 2.1.14 – release notes

Released 2026-11-07 (`v2.1.14`). On top of [2.1.13](2.1.13.md). **MacVPN: root layer 19** (the app asks for **Update required (18 → 19)**: press **Authorize** once).

## English

- **Sign in again when the server ends the session (MacVPN, WinVPN; OpenVPN):** some servers end a running connection after a few hours and ask for a new sign-in (with a new code). Before, this looked like an ordinary drop. Now the notification says **The server ended the session. Click to sign in again.**, and a click connects again: the sign-in or code window comes up. The app does not reconnect by itself, so no window pops up while you are away. The server's own message is written to the connection's log (`[mgmt] the server says: …`); the notification never shows it, because notifications can be seen on the lock screen.

## Magyar

- **Újra-bejelentkezés, ha a szerver befejezi a munkamenetet (MacVPN, WinVPN; OpenVPN):** egyes szerverek néhány óra után bontják a futó kapcsolatot, és új bejelentkezést kérnek (új kóddal). Ez eddig egy sima megszakadásnak látszott. Most az értesítés ezt írja: **A szerver befejezte a munkamenetet. Kattints az újra-bejelentkezéshez.**, és kattintásra az app újra csatlakozik: előjön a bejelentkező vagy kódbekérő ablak. Magától nem csatlakozik újra, így amíg nem vagy a gépnél, nem ugrik fel ablak. A szerver saját üzenete a kapcsolat naplójába kerül (`[mgmt] the server says: …`); az értesítés sosem mutatja, mert az értesítések a zárolt képernyőn is látszanak.
