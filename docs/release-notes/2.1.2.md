# MacVPN, WinVPN and LinVPN 2.1.2 – release notes

Released 2026-10-30 (`v2.1.2`). A small release on top of [2.1.1](2.1.1.md). MacVPN and LinVPN are unchanged apart from the version; the root layer stays 12.

## English

### WinVPN (Windows)

- **Fixed: Download and Install with an administrator's password.** When WinVPN runs under a standard user account and an administrator confirms the update at the UAC prompt, Windows Installer runs as that administrator and could not open the update's log ("Error opening installation log file"). The downloaded package and its log are now readable and writable for the administrator step (still checked before it starts, and the folder stays private). If Windows Installer still cannot open them, WinVPN says so after the restart.
- **Trust This CA in Windows…** works the same way for every administrator account, and an unreadable certificate file gets its own message.
- The update from 2.1.1 to 2.1.2 itself still runs the old installer step: under a standard user account, install 2.1.2 once by hand from the release page; later updates work from the app.

## Magyar

### WinVPN (Windows)

- **Javítva: Letöltés és telepítés egy rendszergazda jelszavával.** Ha a WinVPN normál felhasználói fiókkal fut, és a frissítést egy rendszergazda hagyja jóvá a UAC-ablakban, a Windows Installer annak a rendszergazdának a nevében fut, és nem tudta megnyitni a frissítés naplóját („Hiba történt a telepítés naplófájljának megnyitásakor”). A letöltött csomag és a naplója most olvasható és írható a rendszergazdai lépés számára (indítás előtt továbbra is ellenőrizve, a mappa privát marad). Ha a Windows Installer mégsem tudja megnyitni őket, a WinVPN az újraindulás után megmondja.
- A **CA megbízhatóvá tétele a Windowsban…** ugyanígy működik minden rendszergazdai fiókkal, és az olvashatatlan tanúsítványfájlra külön üzenet jön.
- Maga a 2.1.1 → 2.1.2 frissítés még a régi telepítőlépéssel fut: normál felhasználói fióknál a 2.1.2-t egyszer kézzel telepítsd a kiadási oldalról; a későbbi frissítések már az appból mennek.
