# MacVPN, WinVPN and LinVPN 2.1.5 – release notes

Released 2026-11-04 (`v2.1.5`). A small release on top of [2.1.4](2.1.4.md). The root layer stays 12.

## English

- **Sign-in prompts:** the user name and password prompt and the MFA code prompt take the focus once their one-second input lock is over, with the caret in the first empty field: you can type at once, without clicking into the window. In the first second, keystrokes still go to the app you were using.
- **Battery:** fewer background wake-ups while the app is idle. The status check sleeps until it is due instead of looking every second and still switches to the fast pace as soon as a connection starts. The auto-reconnect planner sleeps until its next timer, the Log tab's reader stops when no Log tab is open, and the menu's clock only ticks while the menu is shown.

## Magyar

- **Bejelentkezési ablakok:** a felhasználónév- és jelszóbekérő, valamint az MFA-kódbekérő ablak az egymásodperces beviteli zár után megkapja a fókuszt, a kurzor pedig az első üres mezőbe kerül: rögtön lehet gépelni, nem kell az ablakba kattintani. Az első másodpercben a billentyűleütések még abba az appba mennek, amelyiket éppen használtad.
- **Akkumulátor:** kevesebb háttérbeli ébresztés, amíg az app tétlen. Az állapotellenőrzés az esedékességig alszik ahelyett, hogy másodpercenként nézne, és egy kapcsolat indulásakor azonnal gyors ütemre vált. Az automatikus újracsatlakozás az ütemezés következő időpontjáig alszik, a Napló fül olvasója leáll, ha nincs Napló fül megnyitva, a menü órája pedig csak akkor jár, ha a menü látszik.
