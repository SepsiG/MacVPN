# MacVPN, WinVPN and LinVPN 2.1.9 – release notes

Released 2026-11-05 (`v2.1.9`). A fix on top of [2.1.8](2.1.8.md). **MacVPN: root layer 15, unchanged** (no new authorization needed). WinVPN and LinVPN: no change.

## English

- **The VPN's DNS with OpenVPN 2.7 (MacVPN):** in 2.1.8 the DNS that an OpenVPN 2.7 server pushes was not applied: OpenVPN's DNS step failed (`dns up command exited with status 127`) and the log said the server sent no DNS. Internet names kept working through the local network's DNS, but the VPN's internal names did not resolve. The DNS step now runs correctly, so the DNS modes of 2.1.8 work with OpenVPN 2.7.

## Magyar

- **A VPN DNS-e OpenVPN 2.7-tel (MacVPN):** a 2.1.8-ban az OpenVPN 2.7-es szerver által küldött DNS nem lépett életbe: az OpenVPN DNS-lépése hibával leállt (`dns up command exited with status 127`), és a napló azt írta, hogy a szerver nem küldött DNS-t. Az internetes nevek a helyi hálózat DNS-ével továbbra is működtek, de a VPN belső nevei nem oldódtak fel. A DNS-lépés most helyesen fut, így a 2.1.8 DNS-módjai OpenVPN 2.7-tel is működnek.
