# MacVPN Rust/Tauri port – implementációs terv

> **For agentic workers:** REQUIRED SUB-SKILL: superpowers:subagent-driven-development. A referencia-implementáció a Swift-kód (`Sources/`, `Resources/root/`, `Tests/`, `scripts/test-root.sh`); minden viselkedés onnan portolandó, a tesztekkel együtt. Ahol a Swift és a spec eltér, a Swift a mérvadó (az audit-javítások ott vannak).

**Goal:** A v0.4.0 MacVPN teljes portja Rustra (Cargo workspace) és Tauri 2-re, funkcionális és biztonsági paritással, frissítésként telepíthetően (1.0.0).

**Spec:** `docs/superpowers/specs/2026-10-18-rust-port-design.md` + `docs/superpowers/specs/2026-10-16-macvpn-design.md`.

**Tech:** Rust stable (rustup, `~/.cargo/bin`), Tauri 2, Svelte + TypeScript (Vite), Node 26; crate-ek: `serde`/`serde_json`, `time` vagy `chrono` (ISO8601), `regex`, `base64`, `sha2`, `ed25519-dalek`, `security-framework` (Keychain), `core-foundation`/`system-configuration`(-sys) vagy saját FFI, `nix`/`libc`, `sys-locale`, `ureq`/`reqwest` (rustls), `tauri`, `tauri-plugin-*` (minimális).

**Általános szabályok minden taskra**
- TDD: előbb a portolt teszt (a Swift-teszt megfelelője), aztán az implementáció.
- `cargo fmt`, `cargo clippy --all-targets -- -D warnings`, `cargo test` zöld minden commit után.
- Nincs `unsafe` a `core`-ban; a `platform-mac`/`mvpn` FFI-je kis, dokumentált modulokban.
- Nincs titok argv-ben, env-ben, naplóban. Temp könyvtár csak biztonságos mkdtemp-pel (a Swift `SecureTempDirectory` szabályai).
- A karbantartó által tiltott cégnév soha nem kerül a repóba (ellenőrzés: a karbantartó `git grep` mintája). Commit-trailer: `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.

## Fázis 1 – Core, mvpn, platform-mac

### Task 1.1: core – modellek, tárolás, kompatibilitás
- `VPNKind`, `Connection` (minden mező: `nativeServiceName`, `nativeServiceID`, `native`, `acknowledgedRiskyDirectives`, OTP-beállítás, …), `ConnectionState`, `ValidationIssue`, `Secrets` (+ `stdinPayload`, `inputError`).
- `ConnectionStore` (0700 könyvtár, 0600 fájlok O_EXCL+rename+fsync, `list/save/load/delete`, legacy profil-takarítás), ranking JSON, system-otp JSON.
- **Kompatibilitási tesztek:** a Swift által írt `meta.json`/ranking/system-otp fixture-ök (generáld a Swift tesztekből vagy kézzel a Swift `JSONEncoder` formátuma szerint) beolvasása és visszaírása bitre azonos mezőkkel.

### Task 1.2: core – validátorok
- OpenVPN: háromszintű tábla (SAFE/RISKY/FORBIDDEN), `argumentSpecs`, `<connection>`, inline blokkok, `setenv` szabályok + tiltólista, `script-security 0|1`, név-minta szabályok, CIDR-kivétel; `validate(text, acknowledged)` → issues + risky + unacknowledged.
- WireGuard, strongSwan (szekciónkénti allowlist), SSTP (config + jelszó-szabály).
- Portold az összes Swift validátor-tesztet és a fixture-öket (OpenVPN 2.7.8 `--help` és `options.c` listák, MikroTik, szolgáltatói profilok); a „minden opció explicit szinten van és szerepel a docs-ban” tesztek is.

### Task 1.3: core – import/export, MFA, management protokoll, frissítés, l10n, napló
- `ConfigImporter` (típusfelismerés, OpenVPN inline-osítás confinement-tel, PKCS#12, hitelesítő-fájl jelöltek, `.mobileconfig` hibaüzenet), `ConfigExporter` (titok-szűrés, 0600 írás).
- `MobileconfigGenerator`, `NativeStartOptions`.
- MFA: SCRV1, static-challenge parse, CRV1, `WebAuthURL` (ASCII host, nincs `%`/`@`), `AuthText.sanitize` (Cf), kód-hozzáfűzés.
- Management protokoll: parser (allowlistes események, sorhossz), parancsépítő (csak `state on`, `hold release`, `username/password "Auth"`, `cr-response`; < 1024 bájt).
- Frissítés: semver, release-parse, asset-útvonal ellenőrzés, repo-ID, 24 órás késleltetés, SHA-256, Ed25519 ellenőrzés a beágyazott kulcsokkal, `.sha256` parse.
- L10n: az EN/HU tábla (`L10n.swift` minden kulcsa) + a UI-katalógus (`Localizable.xcstrings`) egyesítve egy JSON-forrásba, amelyet a core és az UI is használ; nyelvválasztás.
- `LogLine` osztályozás, `LogTailer` (256 KB ablak, inode, UTF-8 határ).
- Az összes megfelelő Swift-teszt portolva.

### Task 1.4: mvpn – root bináris
- Alparancsok a spec 3. fejezete szerint; a bash `mvpn` + `ovpn-dns` + `mvpn-validate` + `mvpn-mgmt` teljes viselkedése (OpenVPN, WireGuard, strongSwan, SSTP up/down/status, DNS backup/restore, `/1` route-ok, zárak, takarítás, maszkolás, root-only naplók, completion-minta, `--accept-risky`, askpass, MFA-bridge + `respond` + UI-állapotfájl, TEST_MODE hookok csak nem-root esetén).
- `scripts/test-root.sh` a Rust bináris ellen: `MVPN` → a lefordított bináris; a hamis eszközök (fake openvpn/wg-quick/sstpc/management szerver) változatlanok. **Minden eset zöld.**
- VERSION 7.

### Task 1.5: platform-mac
- Keychain (`local.macvpn.secrets`, migrációs kompatibilitás), SCNetworkConnection start/stop (linger true, opciók), `scutil --nc list/show` parse, LaunchAgent + SMAppService (FFI vagy `smappservice` kötés), root-telepítő/eltávolító script-generálás + osascript (hash-ellenőrzés, szülőkönyvtár-szabály, régi fájlok törlése), update installer (letöltés, re-hash, hdiutil attach/info, bundle-ellenőrzés, codesign, helper script TERM-trap-pel, double fork), brew bootstrap + minimális env.
- Portolt tesztek (mockolt rendszerhívásokkal).
