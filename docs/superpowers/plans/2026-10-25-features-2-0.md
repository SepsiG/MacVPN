Where a code block below and the real code disagree on a name that already exists, the real code wins: fix the plan's call, not the code.

**Goal:** four user-facing features for both products from the same code: (1) an Appearance setting (Match System / Light / Dark) applied to every window at once; (2) system notifications when a connection connects, drops, is reconnected or fails, with the reason in plain words and a click that opens the connection's Log tab, behind a Settings switch; (3) connections whose engine is not installed stay visible but greyed with "Not installed: <engine> – System Status", and that kind cannot be created or imported; (4) per-connection automatic reconnect after sleep/wake and network loss, only on the same physical network and only when the VPN's networks are not directly reachable there.

**Architecture:** every decision is pure and lives in `macvpn-core` (IP prefixes, the VPN's networks from configs and pushed options) or `macvpn-app-core` (failure classification, notification content and tracking, the reconnect decision and planner, the appearance and engine gates), tested on every OS. The OS facts come from `macvpn-platform-api` traits (`NetworkProbe`, `AppLifecycle::observe_sleep`, the existing `Notifier`) implemented in `platform-mac` (commands parsed by pure parsers, SCDynamicStore, NSWorkspace) and `platform-win` over new safe functions in `macvpn-winsys` (IP Helper, WLAN API: every `unsafe` stays there). The Tauri app wires them (`app/src-tauri/src/{appearance,notifications,reconnect}.rs`) and the Svelte UI shows the settings.

**Tech Stack:** Rust 1.99.1 (pinned), edition 2024, Tauri 2.12.4 (`AppHandle::set_theme`; tao 0.37.1, wry 0.57.0), `windows-sys =0.61.2` (new *features* only), objc2 0.6 / objc2-app-kit 0.3.2 (already locked), Svelte 5 + TS (`node --test`), Node 26.8.2. **No new crate in `Cargo.lock`.**

## Decisions of the maintainer (2026-10-24, binding)

1. **Theme:** a setting System / Light / Dark (default System) in Settings; applies to every window immediately and persists; on macOS also the menu bar popover; on Windows the tray popover and the windows' title bars. Both the web side and the native window theme.
2. **Connection notifications:** macOS Notification Center / Windows toast when a connection connects, drops unexpectedly, reconnects, or fails — with the reason in plain words ("AV VPN disconnected" / "The server stopped responding."); a click opens that connection's Log tab; a Settings switch (default on). No notification for a disconnect the user started.
3. **Missing engines:** a connection whose engine is not installed or not usable (System Status: OpenVPN, WireGuard, strongSwan, SSTP via Homebrew on macOS; OpenVPN, WireGuard, the WinVPN Service on Windows; the native kinds later on Windows) stays visible but greyed with "Not installed: <engine> – System Status" (the link opens System Status) and cannot connect; creating or importing that kind is not offered. The source of truth is the setup report (`SetupReport::is_available` and the engine rows).
4. **Auto-reconnect after sleep/wake and network loss:** per connection. Reconnects only if (a) the physical network is the same as when the connection came up (default gateway IP + MAC, and the Wi-Fi SSID where it can be read) and (b) none of the VPN's networks (routes, AllowedIPs without default routes, DNS servers) is directly connected on the physical network. Otherwise it stays down and a notification says why. OpenVPN's own `ping-restart` keeps working as today; a connection the user disconnected is never reconnected automatically.

## Resolved points (choices this plan makes, with reasons)

### Theme (decision 1)

- **One Tauri call does the native side on both OSes: `AppHandle::set_theme(Option<tauri::Theme>)`** (Tauri 2.12.4 `src/app.rs:941`). On macOS it sets `NSApp.appearance` (tao `set_ns_theme`), which every window, the popover, `NSAlert` dialogs and the WKWebViews follow, and tauri-runtime-wry pushes it into each window's cached theme. On Windows it stores the event loop's preferred theme (used by every window created later, tao `window.rs:1108`), and sends each window `CHANGE_THEME_MSG_ID`: tao switches the title bar to dark/light and emits `ThemeChanged`, on which tauri-runtime-wry calls wry's `set_theme` → WebView2 `SetPreferredColorScheme`. `None` = follow the system again. No platform trait is needed, so no `cfg` and no `unsafe`.
- **The web side needs no CSS change:** `app/ui/src/app.css` already has `color-scheme: light dark` and one `@media (prefers-color-scheme: dark)` block; WKWebView and WebView2 re-evaluate `prefers-color-scheme` when the native theme changes. A UI test pins that there is exactly one such block and no hard-coded `data-theme` (so nobody adds a second mechanism).
- **New windows:** a tiny Tauri plugin (`appearance::plugin()`, `on_window_ready`) calls `window.set_theme(current)` on every new window, so a window created between a change and the event loop's next message has it too (the `corners` plugin is the pattern; `app/src-tauri/src/corners.rs` already asserts every `WebviewWindowBuilder::new(` path goes through plugins).
- **Preference** `appearance` = `"system"` | `"light"` | `"dark"` (anything else or missing = system). Applied in the `.setup()` hook before `tray::create_menu_window`, and immediately by the `set_appearance` command.
- **Limits (documented, not fixed):** Windows' own dialogs (the COM file dialogs, message boxes, the UAC prompt) follow the system theme, not the app's. The tray icon tint stays the taskbar's (`SystemUsesLightTheme`), which is right: the taskbar's background decides. The debug smoke's `MACVPN_SMOKE_DARK` / `_LIGHT` (`platform-mac` `force_appearance`) keeps working and wins in a smoke run.

### Connection notifications (decision 2)

- **The platform layer, not `tauri-plugin-notification`.** The app already posts through `Platform::notifier()` (`crates/platform-api/src/ui.rs` `Notifier`: macOS `UNUserNotificationCenter`, Windows WinRT toasts in `crates/platform-win/src/win/toast.rs`) with click routing to the Log tab (`crates/app-core/src/notify.rs::route_click`, `app/src-tauri/src/notifications.rs::clicked`). On Windows the process AppUserModelID `local.winvpn` is set in `WinPlatform::new` before any window (`toast::set_app_id`), the MSI's Start-menu shortcut carries the same `System.AppUserModel.ID` (checked by `scripts/build-msi.sh` through `scripts/msi-query.ps1`), and toasts go through `CreateToastNotifierWithId("local.winvpn")`: exactly what an unpackaged MSI-installed app needs. The plugin would add crates to `Cargo.lock` (forbidden), would use Tauri's identifier as the AUMID without the shortcut check, and its click handling on desktop is weaker than ours. Known limit (unchanged): a click on a toast whose `ToastNotification` object was dropped (more than 32 newer toasts, or after a restart) does nothing; a dev run without the shortcut shows no toast.
- **Which notifications** (all behind the switch `connectionNotifications`, default on; the MFA "authentication needed", the credential prompt and team catalog notices are not affected by it — they are prompts, not status):
  - **Connected:** the app sees a managed connection go from connecting/awaiting authentication to connected (`ConnectionManager::add_state_listener`). Not at launch for a connection already up (no earlier state seen), not when the vault unlocks.
  - **Reconnected:** the same transition for a connect started by auto-reconnect.
  - **Disconnected (dropped):** the existing `ConnectionEvent::Dropped` (the manager emits it only when a connected connection is found failed/disconnected by a refresh, never for a user's or a lease's disconnect, `Inner::resolve`).
  - **Failed:** the existing `ConnectionEvent::Failed` (a connect that did not come up, also a user-started one: the user wants to know why).
  - **Not reconnected / could not reconnect:** from the auto-reconnect planner (Task 11), with its reason.
  - **No notification** for a disconnect the user (or a lease end, or quitting) started: those paths never emit `Dropped`, and the planner never runs for them. **OpenVPN's own `ping-restart`** is invisible: the helper's status stays `connected` while `openvpn` runs and its log once had `Initialization Sequence Completed` (macOS `crates/helper/src/macos/status.rs`, Windows `crates/helper/src/windows/sys/openvpn.rs::state`), so it produces no notification and no auto-reconnect (kept as is).
- **Reasons in plain words, without leaking anything.** `notify.rs` says "The bodies are generic on purpose: a failure's reason (server, user name, system message) would be visible on the lock screen". That rule stays: the body is one of a closed set of fixed category sentences (`failure_reason::FailureKind`, Task 2) or one of the manager's own fixed reasons (authentication timeout, cancelled, timed out, profile outdated, native failure), never helper stderr, never a log line, never a server, IP or user name. Unknown → the existing "Click to see the log." The classification reads the last 256 KiB of the connection's log through `HelperClient::log_source` (the same source as the Log tab: `/var/log/macvpn/<id>.log` on macOS, the service's `log <id> <offset>` on Windows).
- **Titles:** "%@ connected", "%@ reconnected", "%@ disconnected" (new texts) and the existing "%@: connection failed"; a locked vault's redacted name keeps the existing generic titles (`notify::titled`).

### Missing engines (decision 3)

- **One function decides:** `SetupReport::unavailable_text(kind) -> Option<String>` (platform-api, Task 4): `None` = available; otherwise the localized row label. Its sources, in order: `engine_missing` (WinVPN: the service is absent, unreachable, of another version or degraded — the existing precise text, which already says "Repair WinVPN: …"), `later_reason(kind)` (WinVPN's native kinds), then `missing_engine(kind)` → "Not installed: <engine>" or "Not ready: <engine>" (installed but not usable: an outdated root layer, an OpenVPN that needs a driver repair). Engine names: macOS `Homebrew`, the existing "Permissions (root scripts + sudoers)" row title, `OpenVPN`, `WireGuard tools` (or `bash` when only bash is missing), `strongSwan`, `sstp-client`; Windows `OpenVPN Community`, `WireGuard`. L2TP and Cisco IPsec on macOS never miss an engine.
- **Rows:** `ViewModel::set_unavailable_kinds` (Task 8) sets `available = false`, `switch_enabled = false`, `unavailable_reason = label`, and the new `setup_link = true` (absent from the JSON when false) when a link to System Status helps (not for WinVPN's "later" kinds: there is nothing to install). The UI shows "<type> · Not installed: OpenVPN – System Status" with "System Status" a link (`api.openWindow('setup')`), in the popover rows, the Connections list and the detail header. The old "%@ · Missing tool" text stays in the table (baseline) but is no longer shown.
- **Not offered:** the Connections window's "New" menu lists only available kinds (`ManageView::kinds` filtered); when none is available, one disabled line "Install the VPN tools in System Status to add connections." and a "System Status…" item. **Import** (the open panel, a drop on the window, files opened from Finder/Explorer: all go through `ConnectionsModel::import_paths` → `import_export::import_file`) refuses a file whose kind is unavailable *after* `importer::prepare` determined the kind and *before* anything is saved: "<file>: OpenVPN is not installed. Install it in System Status first." (WinVPN's later kinds: their "later" text; no engine: the engine-missing text) **Team catalogs are not filtered:** a subscription and its updates keep every connection of the catalog (they appear greyed like any other). Reason: the catalog is the team's list, not the user's choice; dropping entries would make the local copy diverge from the published version (the planner and the signed payload compare whole versions), and once the engine is installed the connections work without a re-sync. The control API's `up` keeps its existing answer.
- **Before the first check** (`AppState::setup_checked == false`) nothing is filtered or refused: unknown is not missing.
- **Refresh:** the check already runs at launch, when System Status opens or "Check Again" is clicked, after every install (`system::setup_install_tools` ends with `check`), and daily (the package index thread). New: when the popover or the Connections window is shown and some kind is unavailable, `system::recheck_if_incomplete` runs the check in the background, at most once per 60 s, so a Homebrew install made in Terminal, or an OpenVPN installed by hand, shows up without "Check Again".

### Auto-reconnect (decision 4)

- **Default on.** The maintainer expects it on, and the two conditions remove the case that makes a blind reconnect harmful (being on the VPN's own network, e.g. at the office on 10.20.30.0/24, where routing that subnet into the tunnel would cut the local network). A user who wants a connection to stay down after sleep switches it off for that connection. A connection the user disconnected is never reconnected, whatever the setting.
- **Storage without a format change:** the preference `autoReconnectOff` = the sorted, comma-separated UUIDs of the connections switched off (default on needs no entry). Deleting a connection removes its UUID. Not in the backup (decision of this plan: the backup's preference list is a frozen format).
- **Which connections are candidates** (in memory, per app session):
  1. *Up before sleep:* connected when the system announced sleep (`AppLifecycle::observe_sleep`, new), or — when no sleep announcement came (Windows Modern Standby may skip it) — connected in the manager's states at the moment the wake arrived (the planner is called before the poller refreshes). If such a connection is not connected after wake, or drops within **180 s** after wake, it is a candidate.
  2. *Network loss:* a `Dropped` while the physical network has no default gateway, or within **60 s** after a network change. It waits until the network is back.
  - A `Failed` connect started by the user is never a candidate (the user is looking). A connection whose drop the log classifies as `AuthFailed` or `CertificateProblem` is not retried (a new password or certificate is needed).
- **The decision** (`reconnect::decide`, pure, Task 6), evaluated at least **3 s** after the last wake or network change (DHCP and ARP settle), on a fresh `NetworkSnapshot`:
  - no default gateway → `Wait` (evaluated again on the next network change);
  - the fingerprint recorded when the connection started (`Fingerprint { gateway, gateway_mac, ssid }`) is missing or has no MAC, or the snapshot's gateway MAC cannot be read → `Skip(Unidentified)` (fail closed);
  - gateway IP or MAC differ, or both SSIDs are known and differ → `Skip(DifferentNetwork)`;
  - a VPN prefix (default routes `0.0.0.0/0`, `::/0`, and the `def1` halves `0.0.0.0/1`, `128.0.0.0/1`, `::/1`, `8000::/1` left out) overlaps a directly connected subnet → `Skip(DirectlyReachable(prefix))`; a VPN DNS server inside a directly connected subnet → `Skip(DnsDirectlyReachable(ip))`;
  - otherwise `Reconnect`.
  An SSID that cannot be read on either side (macOS 14.4+ and Windows 11 24H2 hide the SSID from apps without location permission; asking for it would change the bundle's Info.plist and the MSI) is not compared: the gateway's MAC is the identity then. No location permission is requested.
- **The fingerprint** is recorded when a connection starts (its state leaves `disconnected`/`failed` for `connecting`), from a probe that ignores tunnel interfaces (macOS `utun*`, `ipsec*`, `ppp*`, `tun*`, `tap*`, `gif*`, `stf*`, `awdl*`, `llw*`, `bridge*`, `lo*`; Windows interface types `IF_TYPE_PPP`, `IF_TYPE_TUNNEL`, `IF_TYPE_PROP_VIRTUAL`, loopback, and adapters whose description is TAP-Windows / OpenVPN Data Channel Offload / WireGuard / Wintun), so it is the physical network even when another VPN is up. It is recorded again at sleep (same filter) when the probe finds a gateway.
- **The VPN's networks** (`VpnNetworks`, core, Task 1): from the stored config (OpenVPN `route`, `route-ipv6`, `dhcp-option DNS|DNS6`, `dns server <n> address`; WireGuard `AllowedIPs`, `DNS`), plus, when the connection is up, OpenVPN's pushed options from its log (`PUSH: Received control message: 'PUSH_REPLY,…'`: `route`, `route-ipv6`, `dhcp-option DNS|DNS6`, `dns server … address`). IKEv2/strongSwan, SSTP and the native kinds give no prefixes: only the fingerprint check applies to them (documented).
- **Attempts:** at most 3 per candidate (0 s, +10 s, +30 s after the first evaluation), each re-evaluated on a fresh snapshot; a failure classified `AuthFailed`/`CertificateProblem`, a cancelled MFA or credential prompt, or the user's own action on the connection ends it. Success → "reconnected" notice; the last failure → "could not reconnect: <reason>"; a skip → "not reconnected: <reason>" (once per candidate).
- **Interplay:** a user connect or disconnect of the connection, deleting it, and quitting cancel its candidate; when the vault is locked at evaluation time the planner skips with "Unlock the vault to reconnect." (secrets come from the vault). A reconnect may show the MFA or credential prompt, as any connect.
- **Tunnels that survive the sleep (maintainer's decision, 2026-10-25).** An engine may keep its tunnel through a sleep (OpenVPN `ping-restart`, WireGuard): the connection is still `connected` after wake. Once per wake, after `SETTLE`, for every managed connection that was up before the sleep and is still connected, the planner checks the physical network with `reconnect::surviving_check` (Task 6): if one of the VPN's prefixes (default routes left out) overlaps a directly connected subnet, or a VPN DNS server is inside one (the office case), **the app disconnects it** (`DisconnectCause::User`: the user-disconnect rule then applies, so it is not reconnected automatically, and control API leases on it end) and posts "%@ disconnected" / "The VPN’s network is directly reachable here, so it was disconnected." On any other network (a café, another home network) the tunnel is left alone, whatever the fingerprint says. The check runs whatever the connection's "Reconnect Automatically" switch says (it protects the local network, it is not a reconnect). Without a network yet after wake, it waits for the first network change (at most `WAKE_WINDOW` after the wake); a later network change while connected does not trigger it (the trigger is the wake).
- **Where things live:** pure decision and planner in `crates/app-core/src/reconnect.rs` (with fakes in tests); OS probes and watchers behind `NetworkProbe` in the platform crates; the driver thread in `app/src-tauri/src/reconnect.rs`.
- **Detection per OS:**
  - macOS sleep: `NSWorkspaceWillSleepNotification` (new, next to the existing `NSWorkspaceDidWakeNotification` observer in `crates/platform-mac/src/app_hooks.rs`). Network changes: an `SCDynamicStore` watcher on `State:/Network/Global/IPv4` and `State:/Network/Global/IPv6` (new `crates/platform-mac/src/net_watch.rs`, same run-loop-thread pattern as `sc_watch.rs`, bindings added to `sc_ffi.rs`). Probes: `/usr/sbin/netstat -rn -f inet` and `-f inet6` (default routes and their interfaces), `/usr/sbin/arp -n <gateway>` (after one UDP datagram to the gateway's discard port to fill the ARP cache) or `/usr/sbin/ndp -n -a` for IPv6, `/usr/sbin/ipconfig getsummary <if>` (`SSID :`; `<redacted>` = unknown), `getifaddrs` (libc, in `platform-mac`) for the connected subnets — every command through the existing `CommandRunner` with its timeout, every output parsed by pure, fixture-tested functions.
  - Windows sleep: `PBT_APMSUSPEND` in the existing lifecycle window (`crates/platform-win/src/win/lifecycle.rs`), plus `RegisterSuspendResumeNotification(hwnd, DEVICE_NOTIFY_WINDOW_HANDLE)` so Modern Standby delivers suspend/resume too. Network changes: `NotifyIpInterfaceChange` and `NotifyRouteChange2` (winsys). Probes in winsys: `GetIpForwardTable2` (default routes, lowest metric on a physical interface), `ResolveIpNetEntry2` (the gateway's MAC; it resolves actively), `GetAdaptersAddresses` (type, description, oper status, unicast addresses with prefix lengths), `WlanOpenHandle` + `WlanQueryInterface(wlan_intf_opcode_current_connection)` (the SSID; `ERROR_ACCESS_DENIED` without location permission = unknown).

### What does not change

The helper, the WinVPN Service and its pipe protocol; the control API; every serialized format; the tray icon tint; the MFA and credential prompt notifications; `ConnectionEvent`'s two variants (the UI does not listen to `connection-event`; nothing is added there).

// crates/core/src/netaddr.rs
//! IP prefixes (`10.20.30.0/24`, `fd00::/64`): parsing, masking, containment and overlap. Pure; no OS calls.

use std::net::{IpAddr, Ipv4Addr, Ipv6Addr};

/// A network prefix, always stored with the host bits cleared.
#[derive(Debug, Clone, Copy, PartialEq, Eq, Hash, PartialOrd, Ord)]
pub struct IpPrefix {
    pub addr: IpAddr,
    pub len: u8,
}

fn bits(addr: &IpAddr) -> (u128, u8) {
    match addr {
        IpAddr::V4(a) => (u128::from(u32::from(*a)), 32),
        IpAddr::V6(a) => (u128::from(*a), 128),
    }
}

fn mask(len: u8, width: u8) -> u128 {
    if len == 0 { 0 } else { (!0u128 << (width - len)) & if width == 32 { u128::from(u32::MAX) } else { !0u128 } }
}

impl IpPrefix {
    /// `addr/len` or a bare address (a host prefix). Strict: no spaces, no host names, `len` in range.
    pub fn parse(text: &str) -> Option<IpPrefix> {
        let (addr, len) = match text.split_once('/') {
            Some((a, l)) => (a, Some(l)),
            None => (text, None),
        };
        let addr: IpAddr = addr.parse().ok()?;
        let width = bits(&addr).1;
        let len = match len {
            None => width,
            Some(l) if !l.is_empty() && l.bytes().all(|b| b.is_ascii_digit()) && l.len() <= 3 => l.parse().ok()?,
            Some(_) => return None,
        };
        IpPrefix::new(addr, len)
    }

    /// The prefix `addr/len` with the host bits cleared; `None` when `len` is too long.
    pub fn new(addr: IpAddr, len: u8) -> Option<IpPrefix> {
        let (value, width) = bits(&addr);
        if len > width {
            return None;
        }
        let net = value & mask(len, width);
        let addr = if width == 32 { IpAddr::V4(Ipv4Addr::from(net as u32)) } else { IpAddr::V6(Ipv6Addr::from(net)) };
        Some(IpPrefix { addr, len })
    }

    /// OpenVPN's `route <network> <netmask>`: a contiguous mask only.
    pub fn from_mask(addr: Ipv4Addr, netmask: Ipv4Addr) -> Option<IpPrefix> {
        let m = u32::from(netmask);
        let len = m.leading_ones();
        if m.checked_shl(len).unwrap_or(0) != 0 {
            return None;
        }
        IpPrefix::new(IpAddr::V4(addr), len as u8)
    }

    pub fn contains(&self, ip: &IpAddr) -> bool {
        let (net, width) = bits(&self.addr);
        let (value, other) = bits(ip);
        width == other && value & mask(self.len, width) == net
    }

    pub fn overlaps(&self, other: &IpPrefix) -> bool {
        self.contains(&other.addr) || other.contains(&self.addr)
    }

    /// `0.0.0.0/0`, `::/0` and the `def1` halves (`0.0.0.0/1`, `128.0.0.0/1`, `::/1`, `8000::/1`).
    pub fn is_default_route(&self) -> bool {
        self.len <= 1
    }
}

// crates/core/src/vpn_networks.rs
//! The networks a VPN routes and its DNS servers, for the auto-reconnect check "is the VPN's network directly
//! reachable here?": from the stored config (OpenVPN, WireGuard) and from OpenVPN's PUSH_REPLY in the connection's
//! log. Default routes are left out (a full tunnel overlaps every network). Other kinds give nothing.

use crate::models::VPNKind;
use crate::netaddr::IpPrefix;
use std::net::{IpAddr, Ipv4Addr};

#[derive(Debug, Clone, Default, PartialEq, Eq)]
pub struct VpnNetworks {
    pub prefixes: Vec<IpPrefix>,
    pub dns: Vec<IpAddr>,
}

const PUSH_MARK: &str = "PUSH_REPLY,";

impl VpnNetworks {
    pub fn from_config(kind: VPNKind, config: &str) -> VpnNetworks {
        let mut n = VpnNetworks::default();
        match kind {
            VPNKind::Openvpn => {
                for line in config.lines() {
                    n.openvpn_option(line.trim());
                }
            }
            VPNKind::Wireguard => n.wireguard(config),
            _ => {}
        }
        n
    }

    pub fn is_empty(&self) -> bool {
        self.prefixes.is_empty() && self.dns.is_empty()
    }

    /// OpenVPN's pushed options, from the log lines of the current session (the last PUSH_REPLY wins nothing:
    /// every one adds, duplicates are kept once).
    pub fn add_pushed(&mut self, lines: &[String]) {
        for line in lines {
            let Some(start) = line.find(PUSH_MARK) else { continue };
            let rest = &line[start + PUSH_MARK.len()..];
            let rest = rest.split('\'').next().unwrap_or(rest);
            for option in rest.split(',') {
                self.openvpn_option(option.trim());
            }
        }
    }

    fn add_prefix(&mut self, prefix: Option<IpPrefix>) {
        if let Some(p) = prefix
            && !p.is_default_route()
            && !self.prefixes.contains(&p)
        {
            self.prefixes.push(p);
        }
    }

    fn add_dns(&mut self, ip: Option<IpAddr>) {
        if let Some(ip) = ip
            && !self.dns.contains(&ip)
        {
            self.dns.push(ip);
        }
    }

    fn openvpn_option(&mut self, line: &str) {
        let words: Vec<&str> = line.split_whitespace().collect();
        match words.as_slice() {
            ["route", net, rest @ ..] => {
                let Ok(net) = net.parse::<Ipv4Addr>() else { return };
                let netmask = rest.first().and_then(|m| m.parse::<Ipv4Addr>().ok()).unwrap_or(Ipv4Addr::BROADCAST);
                self.add_prefix(IpPrefix::from_mask(net, netmask));
            }
            ["route-ipv6", prefix, ..] => self.add_prefix(IpPrefix::parse(prefix)),
            ["dhcp-option", "DNS" | "DNS6", ip, ..] => self.add_dns(ip.parse().ok()),
            ["dns", "server", _, "address", ip, ..] => {
                // `dns server <n> address <ip>[:port]` (OpenVPN 2.6); IPv6 may be bracketed.
                let ip = ip.trim_start_matches('[').split(']').next().unwrap_or(ip);
                let ip = if ip.matches(':').count() == 1 { ip.split(':').next().unwrap_or(ip) } else { ip };
                self.add_dns(ip.parse().ok());
            }
            _ => {}
        }
    }

    fn wireguard(&mut self, config: &str) {
        for line in config.lines() {
            let Some((key, value)) = line.split_once('=') else { continue };
            let key = key.trim().to_ascii_lowercase();
            let values = value.split(',').map(str::trim).filter(|v| !v.is_empty());
            match key.as_str() {
                "allowedips" => values.for_each(|v| self.add_prefix(IpPrefix::parse(v))),
                // Non-addresses in DNS are search domains.
                "dns" => values.for_each(|v| self.add_dns(v.parse().ok())),
                _ => {}
            }
        }
    }
}

// crates/app-core/src/failure_reason.rs
//! Why a connection failed or dropped, in plain words: the last log line that matches one of a few patterns decides
//! a category; each category has one fixed sentence. The sentence never quotes the log (a notification is visible
//! on the lock screen: no server, address, user name or system message).

use macvpn_core::l10n;

#[derive(Debug, Clone, Copy, PartialEq, Eq)]
pub enum FailureKind {
    ServerNotResponding,
    ServerUnreachable,
    NameNotResolved,
    AuthFailed,
    CertificateProblem,
    NetworkLost,
    Unknown,
}

impl FailureKind {
    /// A reconnect can help (not for a refused password or certificate).
    pub fn worth_retrying(self) -> bool {
        !matches!(self, FailureKind::AuthFailed | FailureKind::CertificateProblem)
    }
}

/// (pattern, category), matched as substrings. Order inside one line: the first pattern wins.
const PATTERNS: &[(&str, FailureKind)] = &[
    ("AUTH_FAILED", FailureKind::AuthFailed),
    ("AUTHENTICATION_FAILED", FailureKind::AuthFailed),
    ("VERIFY ERROR", FailureKind::CertificateProblem),
    ("certificate verify failed", FailureKind::CertificateProblem),
    ("Cannot resolve host address", FailureKind::NameNotResolved),
    ("Inactivity timeout (--ping-restart)", FailureKind::ServerNotResponding),
    ("Inactivity timeout (--ping-exit)", FailureKind::ServerNotResponding),
    ("retransmits", FailureKind::ServerNotResponding),
    ("peer not responding", FailureKind::ServerNotResponding),
    ("TLS key negotiation failed", FailureKind::ServerUnreachable),
    ("Connection refused", FailureKind::ServerUnreachable),
    ("Connection timed out", FailureKind::ServerUnreachable),
    ("Network is unreachable", FailureKind::NetworkLost),
    ("No route to host", FailureKind::NetworkLost),
];

/// The category of the last classified line (scanning from the end).
pub fn classify(lines: &[String]) -> FailureKind {
    lines
        .iter()
        .rev()
        .find_map(|line| PATTERNS.iter().find(|(p, _)| line.contains(p)).map(|(_, k)| *k))
        .unwrap_or(FailureKind::Unknown)
}

/// The fixed sentence; `None` for `Unknown` (the caller keeps its generic text).
pub fn plain(kind: FailureKind) -> Option<String> {
    let text = match kind {
        FailureKind::ServerNotResponding => "The server stopped responding.",
        FailureKind::ServerUnreachable => "The server could not be reached.",
        FailureKind::NameNotResolved => "The server’s name could not be resolved.",
        FailureKind::AuthFailed => "The server refused the sign-in.",
        FailureKind::CertificateProblem => "A certificate was not accepted.",
        FailureKind::NetworkLost => "The network connection was lost.",
        FailureKind::Unknown => return None,
    };
    Some(l10n::tr(text, &[]))
}

//! The Appearance setting: follow the system, or force light or dark for every window of the app.

use macvpn_platform_api::PreferenceStore;

pub const APPEARANCE_KEY: &str = "appearance";

#[derive(Debug, Clone, Copy, PartialEq, Eq, Default)]
pub enum Appearance {
    #[default]
    System,
    Light,
    Dark,
}

impl Appearance {
    pub fn parse(raw: &str) -> Option<Appearance> {
        match raw {
            "system" => Some(Appearance::System),
            "light" => Some(Appearance::Light),
            "dark" => Some(Appearance::Dark),
            _ => None,
        }
    }

    pub fn raw_value(self) -> &'static str {
        match self {
            Appearance::System => "system",
            Appearance::Light => "light",
            Appearance::Dark => "dark",
        }
    }

    pub fn load(prefs: &dyn PreferenceStore) -> Appearance {
        prefs.string(APPEARANCE_KEY).and_then(|s| Appearance::parse(&s)).unwrap_or_default()
    }

    pub fn store(self, prefs: &dyn PreferenceStore) {
        prefs.set_string(APPEARANCE_KEY, self.raw_value());
    }
}

//! `NSApp.appearance`, which the popover, alerts and web views follow; Windows: each window's title bar and its
//! WebView2's preferred colour scheme, and the event loop's default for windows created later). The web views'

use macvpn_app_core::appearance::Appearance;

fn theme(a: Appearance) -> Option<Theme> {
    match a {

        Appearance::Light => Some(Theme::Light),
        Appearance::Dark => Some(Theme::Dark),

/// An engine a kind needs that is not usable: its name, and whether it is installed (then it needs a repair or an
/// update, "Not ready") or not ("Not installed").
#[derive(Debug, Clone, PartialEq, Eq)]
pub struct MissingEngine {
    pub name: String,
    pub installed: bool,
}

impl MissingEngine {
    pub fn label(&self) -> String {
        let text = if self.installed { "Not ready: %@" } else { "Not installed: %@" };
        macvpn_core::l10n::tr(text, &[macvpn_core::l10n::Arg::Str(&self.name)])
    }
}

/// The name of a helper-run kind's tools on macOS (the Homebrew packages' names as System Status lists them).
fn tool_package(kind: VPNKind) -> &'static str {
    match kind {
        VPNKind::Openvpn => "OpenVPN",
        VPNKind::Wireguard => "WireGuard tools",
        VPNKind::Strongswan => "strongSwan",
        VPNKind::Sstp => "sstp-client",
        VPNKind::L2tp | VPNKind::Cisco => "",
    }
}

impl SetupReport {
    /// The engine `kind` lacks; `None` when it is available, or when the reason is not an engine
    /// ([`Self::engine_missing`], a later kind).
    pub fn missing_engine(&self, kind: VPNKind) -> Option<MissingEngine> {
        if self.engine_missing.is_some() || self.later_reason(kind).is_some() || self.is_available(kind) {
            return None;
        }
        let missing = |name: &str, installed: bool| Some(MissingEngine { name: name.to_string(), installed });
        if let Some(e) = &self.engine {
            let tr = |s: &str| macvpn_core::l10n::tr(s, &[]);
            if !e.service.usable {
                return missing(&tr("WinVPN Service"), true);
            }
            let (name, row) = match kind {
                VPNKind::Openvpn => ("OpenVPN Community", &e.openvpn),
                VPNKind::Wireguard => ("WireGuard", &e.wireguard),
                _ => return None,
            };
            return missing(name, row.action != Some("install"));
        }
        if kind.is_native() {
            return None;
        }
        if self.package_manager.is_none() {
            return missing("Homebrew", false);
        }
        if !self.root_ok() {
            let title = macvpn_core::l10n::tr("Permissions (root scripts + sudoers)", &[]);
            return missing(&title, self.installed_root_version.is_some());
        }
        let needed = self.required_tools.iter().find(|(k, _)| *k == kind).map(|(_, t)| *t).unwrap_or(&[]);
        let absent: Vec<&str> =
            needed.iter().copied().filter(|t| self.missing_tools.iter().any(|m| m == t)).collect();
        // Only bash missing (WireGuard's wg-quick needs Homebrew's bash): name it.
        let name = if absent == ["bash"] { "bash" } else { tool_package(kind) };
        missing(name, false)
    }

    /// `None`: a connection of `kind` can start. Otherwise the row's label: the engine-missing text, the later
    /// text, or "Not installed: …" / "Not ready: …".
    pub fn unavailable_text(&self, kind: VPNKind) -> Option<String> {
        if self.is_available(kind) {
            return None;
        }
        if let Some(reason) = &self.engine_missing {
            return Some(reason.clone());
        }
        if let Some(reason) = self.later_reason(kind) {
            return Some(reason.to_string());
        }
        Some(self.missing_engine(kind).map(|m| m.label()).unwrap_or_else(|| macvpn_core::l10n::tr("Not ready: %@", &[macvpn_core::l10n::Arg::Str(kind.display_name())])))
    }
}

//! readable) and the subnets directly connected to physical interfaces. Tunnel interfaces (VPNs) are never part
//! of it. Each platform implements the probe; the decisions are app-core's.

use crate::PlatformError;
use macvpn_core::netaddr::IpPrefix;
use std::io;
use std::net::IpAddr;

#[derive(Debug, Clone, PartialEq, Eq)]
pub struct Gateway {
    pub ip: IpAddr,
    /// `None`: it could not be resolved.
    pub mac: Option<[u8; 6]>,
    /// The interface the default route leaves through (`en0`, the adapter's alias).
    pub interface: String,
    /// The Wi-Fi network's name; `None` on a wired interface or when the system does not tell (location
    /// permission).
    pub ssid: Option<String>,
}

#[derive(Debug, Clone, Default, PartialEq, Eq)]
pub struct NetworkSnapshot {
    /// The default gateway of the physical interface with the best route; `None`: no network.
    pub gateway: Option<Gateway>,
    /// The subnets of the up, physical interfaces (no loopback, link-local or tunnel).
    pub connected: Vec<IpPrefix>,
}

impl NetworkSnapshot {
    pub fn has_network(&self) -> bool {
        self.gateway.is_some()
    }
}

pub trait NetworkProbe: Send + Sync {
    /// Blocking (a few hundred milliseconds at most; the platform bounds its calls).
    fn snapshot(&self) -> Result<NetworkSnapshot, PlatformError>;
    /// Calls `on_change` (on the watcher's thread) when addresses or routes change. Dropping the box stops it.
    fn watch(&self, on_change: Box<dyn Fn() + Send>) -> io::Result<Box<dyn Send>>;
}

/// No probe (tests, the sandbox, a platform without one): never reconnects.
#[derive(Debug, Default, Clone, Copy)]
pub struct NoNetworkProbe;

impl NetworkProbe for NoNetworkProbe {
    fn snapshot(&self) -> Result<NetworkSnapshot, PlatformError> {
        Err(PlatformError::Unsupported { what: "network probe" })
    }

    fn watch(&self, _on_change: Box<dyn Fn() + Send>) -> io::Result<Box<dyn Send>> {
        Ok(Box::new(()))
    }
}

//! Automatic reconnect after sleep and network loss (maintainer decision 4, 2026-10-24): the pure decision, the
//! per-connection opt-out and (below) the planner. A connection reconnects only on the physical network it started
//! on (gateway IP + MAC, the SSID when both sides know it) and only when none of its routed networks or DNS servers
//! is directly connected there. Everything fails closed: an unidentified network is not reconnected.

use macvpn_core::netaddr::IpPrefix;
use macvpn_core::vpn_networks::VpnNetworks;
use macvpn_platform_api::{NetworkSnapshot, PreferenceStore};
use std::collections::BTreeSet;
use std::net::IpAddr;
use uuid::Uuid;

/// The preference: the connections switched off (sorted UUIDs, comma-separated). Default on.
pub const OFF_KEY: &str = "autoReconnectOff";

#[derive(Debug, Clone, PartialEq, Eq)]
pub struct Fingerprint {
    pub gateway: IpAddr,
    pub gateway_mac: [u8; 6],
    pub ssid: Option<String>,
}

#[derive(Debug, Clone, PartialEq, Eq)]
pub enum Skip {
    DifferentNetwork,
    Unidentified,
    DirectlyReachable(IpPrefix),
    DnsDirectlyReachable(IpAddr),
    VaultLocked,
}

#[derive(Debug, Clone, PartialEq, Eq)]
pub enum Decision {
    Reconnect,
    /// No network yet: evaluate again on the next change.
    Wait,
    Skip(Skip),
}

/// `None` without a gateway MAC (it cannot identify the network).
pub fn fingerprint(s: &NetworkSnapshot) -> Option<Fingerprint> {
    let g = s.gateway.as_ref()?;
    Some(Fingerprint { gateway: g.ip, gateway_mac: g.mac?, ssid: g.ssid.clone() })
}

pub fn decide(before: Option<&Fingerprint>, now: &NetworkSnapshot, networks: &VpnNetworks) -> Decision {
    if !now.has_network() {
        return Decision::Wait;
    }
    let (Some(before), Some(current)) = (before, fingerprint(now)) else {
        return Decision::Skip(Skip::Unidentified);
    };
    let ssid_differs = matches!((&before.ssid, &current.ssid), (Some(a), Some(b)) if a != b);
    if before.gateway != current.gateway || before.gateway_mac != current.gateway_mac || ssid_differs {
        return Decision::Skip(Skip::DifferentNetwork);
    }
    for p in networks.prefixes.iter().filter(|p| !p.is_default_route()) {
        if now.connected.iter().any(|c| c.overlaps(p)) {
            return Decision::Skip(Skip::DirectlyReachable(*p));
        }
    }
    for ip in &networks.dns {
        if now.connected.iter().any(|c| c.contains(ip)) {
            return Decision::Skip(Skip::DnsDirectlyReachable(*ip));
        }
    }
    Decision::Reconnect
}

/// A tunnel that survived the sleep (still connected after wake): `Some` when the VPN's network or DNS server is
/// directly reachable on the physical network now (it must be disconnected). The fingerprint does not matter: on
/// any other network the tunnel stays. No network → `None`.
pub fn surviving_check(now: &NetworkSnapshot, networks: &VpnNetworks) -> Option<Skip> {
    if !now.has_network() {
        return None;
    }
    if let Some(p) =
        networks.prefixes.iter().filter(|p| !p.is_default_route()).find(|p| now.connected.iter().any(|c| c.overlaps(p)))
    {
        return Some(Skip::DirectlyReachable(*p));
    }
    networks.dns.iter().find(|ip| now.connected.iter().any(|c| c.contains(ip))).map(|ip| Skip::DnsDirectlyReachable(*ip))
}

fn off_set(prefs: &dyn PreferenceStore) -> BTreeSet<String> {
    prefs.string(OFF_KEY).unwrap_or_default().split(',').filter(|s| !s.is_empty()).map(str::to_string).collect()
}

pub fn is_enabled(prefs: &dyn PreferenceStore, id: &Uuid) -> bool {
    !off_set(prefs).contains(&macvpn_core::models::uuid_string(id))
}

pub fn set_enabled(prefs: &dyn PreferenceStore, id: &Uuid, on: bool) {
    let mut set = off_set(prefs);
    let key = macvpn_core::models::uuid_string(id);
    if on {
        set.remove(&key);
    } else {
        set.insert(key);
    }
    prefs.set_string(OFF_KEY, &set.into_iter().collect::<Vec<_>>().join(","));
}

// crates/app-core/src/connection_notices.rs
//! Connection status notifications (maintainer decision 2): connected, reconnected, disconnected, failed, not
//! reconnected. The texts are fixed sentences that name only the connection (lock-screen rule of `notify`).

use crate::failure_reason::{FailureKind, plain};
use crate::manager::{auth_cancelled_reason, auth_timeout_reason, native_failure_reason, profile_outdated_reason};
use crate::notify::{CONNECTION_KEY, NotificationContent};
use crate::reconnect::Skip;
use macvpn_core::l10n::{self, Arg};
use macvpn_core::models::ConnectionState;
use macvpn_platform_api::PreferenceStore;
use std::collections::{HashMap, HashSet};

pub const ENABLED_KEY: &str = "connectionNotifications";

pub fn enabled(prefs: &dyn PreferenceStore) -> bool {
    prefs.bool(ENABLED_KEY).unwrap_or(true)
}

#[derive(Debug, Clone, PartialEq, Eq)]
pub enum Notice {
    Connected { key: String, name: String },
    Reconnected { key: String, name: String },
    Dropped { key: String, name: String, reason: Option<String> },
    Failed { key: String, name: String, reason: Option<String> },
    NotReconnected { key: String, name: String, why: Skip },
    ReconnectFailed { key: String, name: String, reason: Option<String> },
}

#[derive(Debug, Default)]
pub struct NoticeTracker {
    last: HashMap<String, ConnectionState>,
    auto: HashSet<String>,
}

impl NoticeTracker {
    /// The next connect of `key` was started by auto-reconnect.
    pub fn mark_auto(&mut self, key: &str) {
        self.auto.insert(key.to_string());
    }

    pub fn on_state(&mut self, key: &str, name: &str, state: &ConnectionState) -> Option<Notice> {
        let previous = self.last.insert(key.to_string(), state.clone());
        let was_connecting = matches!(previous, Some(ConnectionState::Connecting | ConnectionState::AwaitingAuth(_)));
        if !matches!(state, ConnectionState::Connected { .. }) {
            if !matches!(state, ConnectionState::Connecting | ConnectionState::AwaitingAuth(_)) {
                self.auto.remove(key);
            }
            return None;
        }
        if !was_connecting {
            return None;
        }
        let (key, name) = (key.to_string(), name.to_string());
        Some(if self.auto.remove(&key) { Notice::Reconnected { key, name } } else { Notice::Connected { key, name } })
    }
}

/// The body for a failure: the log's category, else a manager reason only if it is one of its fixed texts.
pub fn reason_text(kind: FailureKind, manager_reason: Option<&str>) -> Option<String> {
    plain(kind).or_else(|| {
        let reason = manager_reason?;
        let fixed = [auth_timeout_reason(), auth_cancelled_reason(), native_failure_reason(), profile_outdated_reason()];
        fixed.into_iter().find(|f| f == reason)
    })
}

fn skip_text(why: &Skip) -> String {
    let text = match why {
        Skip::DifferentNetwork => "You are on a different network.",
        Skip::Unidentified => "The network could not be identified.",
        Skip::DirectlyReachable(_) => "The VPN’s network is directly reachable here.",
        Skip::DnsDirectlyReachable(_) => "The VPN’s DNS server is directly reachable here.",
        Skip::VaultLocked => "Unlock the vault to reconnect.",
    };
    l10n::tr(text, &[])
}

```rust
//! Parsers of the network commands' output (`netstat -rn`, `arp -n`, `ipconfig getsummary`), pure and
//! fixture-tested. Tunnel interfaces (VPNs, bridges, AWDL, loopback) are never the physical network.

use std::net::IpAddr;

const TUNNEL_PREFIXES: &[&str] = &["utun", "ipsec", "ppp", "tun", "tap", "gif", "stf", "awdl", "llw", "bridge", "lo"];

pub fn is_tunnel_interface(name: &str) -> bool {
    TUNNEL_PREFIXES.iter().any(|p| name.strip_prefix(p).is_some_and(|rest| rest.bytes().all(|b| b.is_ascii_digit())))
}

/// The `default` routes with a gateway address, on physical interfaces, in the table's order (the first is used).
pub fn default_routes(netstat: &str) -> Vec<(IpAddr, String)> {
    netstat
        .lines()
        .filter_map(|line| {
            let cols: Vec<&str> = line.split_whitespace().collect();
            if cols.first() != Some(&"default") || cols.len() < 4 {
                return None;
            }
            // IPv6 gateways carry a scope (`fe80::1%en0`).
            let gw: IpAddr = cols[1].split('%').next()?.parse().ok()?;
            let iface = cols[3].to_string();
            (!is_tunnel_interface(&iface)).then_some((gw, iface))
        })
        .collect()
}

/// `? (192.168.1.1) at a4:2b:b0:0:0:1 on en0 …`; `(incomplete)` or no entry → `None`.
pub fn gateway_mac(arp: &str) -> Option<[u8; 6]> {
    let after = arp.split(" at ").nth(1)?;
    let word = after.split_whitespace().next()?;
    let parts: Vec<&str> = word.split(':').collect();
    if parts.len() != 6 {
        return None;
    }
    let mut mac = [0u8; 6];
    for (slot, part) in mac.iter_mut().zip(parts) {
        *slot = u8::from_str_radix(part, 16).ok()?;
    }
    Some(mac)
}

/// `  SSID : Home` of `ipconfig getsummary <if>`; `<redacted>` (no location permission) → `None`.
pub fn ssid(summary: &str) -> Option<String> {
    summary.lines().find_map(|line| {
        let (key, value) = line.split_once(" : ")?;
        (key.trim() == "SSID").then(|| value.trim().to_string())
    })
    .filter(|s| !s.is_empty() && s != "<redacted>")
}
```

//! `NetworkProbe` for macOS: commands through the crate's `CommandRunner` (each with its timeout) plus
//! `getifaddrs` for the connected subnets.

use crate::command::CommandRunner;
use crate::net_parse;
use macvpn_core::netaddr::IpPrefix;
use macvpn_platform_api::{Gateway, NetworkSnapshot, PlatformError};

pub struct MacNetworkProbe<R: CommandRunner> {
    pub runner: R,
}

impl<R: CommandRunner> MacNetworkProbe<R> {
    pub fn snapshot(&self) -> Result<NetworkSnapshot, PlatformError> {
        let run = |cmd: &str, args: &[&str]| {
            let args: Vec<String> = args.iter().map(|a| a.to_string()).collect();
            self.runner.run(cmd, &args, None).map(|r| r.stdout).unwrap_or_default()
        };
        let mut routes = net_parse::default_routes(&run("/usr/sbin/netstat", &["-rn", "-f", "inet"]));
        if routes.is_empty() {
            routes = net_parse::default_routes(&run("/usr/sbin/netstat", &["-rn", "-f", "inet6"]));
        }
        let gateway = routes.into_iter().next().map(|(ip, interface)| {
            prime_arp(&ip);
            let mac = net_parse::gateway_mac(&run("/usr/sbin/arp", &["-n", &ip.to_string()]));
            let ssid = net_parse::ssid(&run("/usr/sbin/ipconfig", &["getsummary", &interface]));
            Gateway { ip, mac, interface, ssid }
        });
        Ok(NetworkSnapshot { gateway, connected: connected_prefixes() })
    }
}

/// One UDP datagram to the gateway's discard port, so the ARP cache has its entry (std only, no raw socket).
fn prime_arp(ip: &std::net::IpAddr) {
    let bind = if ip.is_ipv4() { "0.0.0.0:0" } else { "[::]:0" };
    if let Ok(s) = std::net::UdpSocket::bind(bind) {
        let _ = s.send_to(&[0], (*ip, 9));
        std::thread::sleep(std::time::Duration::from_millis(150));
    }
}

/// The subnets of up, physical interfaces (`getifaddrs`; loopback, link-local and tunnels left out).
pub fn connected_prefixes() -> Vec<IpPrefix> {
    crate::sys::interface_prefixes()
        .into_iter()
        .filter(|(name, _)| !net_parse::is_tunnel_interface(name))
        .map(|(_, p)| p)
        .filter(|p| !is_link_local(p))
        .collect()
}

fn is_link_local(p: &IpPrefix) -> bool {
    match p.addr {
        std::net::IpAddr::V4(a) => a.is_link_local(),
        std::net::IpAddr::V6(a) => (a.segments()[0] & 0xffc0) == 0xfe80,
    }
}

//! Which adapter is the physical network (pure; the Win32 reads are `macvpn_winsys::net`).

use macvpn_core::netaddr::IpPrefix;
use std::net::IpAddr;

/// What `macvpn_winsys::net::adapters` reads of one adapter.
#[derive(Debug, Clone, PartialEq, Eq)]
pub struct Adapter {
    pub alias: String,
    /// `IF_TYPE_*` (6 Ethernet, 71 Wi-Fi, 23 PPP, 24 loopback, 53 proprietary virtual, 131 tunnel).
    pub if_type: u32,
    pub description: String,
    pub up: bool,
    /// The next hop of this adapter's default route, if it has one.
    pub gateway: Option<IpAddr>,
    /// The default route's metric plus the interface metric (lower wins).
    pub route_metric: u32,
    pub prefixes: Vec<IpPrefix>,
    pub luid: u64,
    pub guid: [u8; 16],
}

const VIRTUAL_TYPES: &[u32] = &[23, 24, 53, 131];
const VPN_DESCRIPTIONS: &[&str] = &["TAP-Windows", "OpenVPN Data Channel Offload", "WireGuard", "Wintun"];

pub fn is_physical(a: &Adapter) -> bool {
    a.up && !VIRTUAL_TYPES.contains(&a.if_type) && !VPN_DESCRIPTIONS.iter().any(|d| a.description.contains(d))
}

/// The physical adapter with the best default route through a real next hop.
pub fn physical_gateway(adapters: &[Adapter]) -> Option<&Adapter> {
    adapters
        .iter()
        .filter(|a| is_physical(a) && a.gateway.is_some_and(|g| !g.is_unspecified()))
        .min_by_key(|a| a.route_metric)
}

/// Wi-Fi adapters (the SSID is asked only for them).
pub fn is_wifi(a: &Adapter) -> bool {
    a.if_type == 71
}

use crate::connection_notices::Notice;
use crate::failure_reason::{FailureKind, plain};
use macvpn_core::date::Date;
use std::collections::{HashMap, HashSet};

/// Drops within this many seconds after a wake count for connections that were up before the sleep.
pub const WAKE_WINDOW: f64 = 180.0;
/// Drops within this many seconds after a network change count as caused by it.
pub const NETWORK_WINDOW: f64 = 60.0;
/// Wait this long after a wake, a change or a drop before probing (DHCP, ARP).
pub const SETTLE: f64 = 3.0;
/// The delays before the second and the third attempt.
pub const RETRY_DELAYS: [f64; 2] = [10.0, 30.0];

#[derive(Debug, Clone, PartialEq, Eq)]
pub enum Action {
    Connect(String),
    /// A surviving tunnel on its own network: the app disconnects it (`DisconnectCause::User`).
    Disconnect(String),
    Notify(Notice),
}

#[derive(Debug, Clone)]
struct Candidate {
    name: String,
    attempts: usize,
    /// `None`: waits for a network change.
    next: Option<Date>,
    attempting: bool,
}

#[derive(Debug, Default)]
pub struct Planner {
    fingerprints: HashMap<String, Fingerprint>,
    networks: HashMap<String, VpnNetworks>,
    user_off: HashSet<String>,
    up_at_sleep: HashSet<String>,
    slept: bool,
    woke_at: Option<Date>,
    changed_at: Option<Date>,
    network_down: bool,
    candidates: HashMap<String, Candidate>,
    /// The surviving-tunnel check of this wake: when it is due (`None`: done, or waiting for a network change).
    survivors_at: Option<Date>,
    /// The check still has to run (it waits for a network change when there was none).
    survivors_pending: bool,
}

fn later(a: Date, b: Option<Date>) -> Date {
    match b {
        Some(b) if b.time_interval_since(a) > 0.0 => b,
        _ => a,
    }
}

impl Planner {
    /// The connection left `disconnected`/`failed` for `connecting`. `by_planner`: our own attempt.
    pub fn connect_started(&mut self, key: &str, fp: Option<Fingerprint>, by_planner: bool) {
        if by_planner {
            return;
        }
        self.user_off.remove(key);
        self.candidates.remove(key);
        match fp {
            Some(fp) => self.fingerprints.insert(key.to_string(), fp),
            None => self.fingerprints.remove(key),
        };
    }

    /// Connected: its networks (config + pushed) for the next decision; any candidate is done.
    pub fn connected(&mut self, key: &str, networks: VpnNetworks) {
        self.networks.insert(key.to_string(), networks);
        self.candidates.remove(key);
    }

    pub fn user_disconnected(&mut self, key: &str) {
        self.user_off.insert(key.to_string());
        self.candidates.remove(key);
    }

    /// A deleted connection.
    pub fn forget(&mut self, key: &str) {
        self.fingerprints.remove(key);
        self.networks.remove(key);
        self.user_off.remove(key);
        self.up_at_sleep.remove(key);
        self.candidates.remove(key);
    }

    /// The system is about to sleep: `connected` are the connected keys; `fp` the physical network now (it
    /// replaces theirs when known).
    pub fn sleep(&mut self, connected: &[String], fp: Option<Fingerprint>) {
        self.slept = true;
        self.up_at_sleep = connected.iter().cloned().collect();
        if let Some(fp) = fp {
            for key in connected {
                self.fingerprints.insert(key.clone(), fp.clone());
            }
        }
    }

    /// The system woke. Without a sleep announcement, `connected` (the states before the first refresh) stands in.
    pub fn wake(&mut self, now: Date, connected: &[String]) {
        if !self.slept {
            self.up_at_sleep = connected.iter().cloned().collect();
        }
        self.slept = false;
        self.woke_at = Some(now);
        self.survivors_pending = true;
        self.survivors_at = Some(now.adding(SETTLE));
        for c in self.candidates.values_mut() {
            c.next = Some(later(now.adding(SETTLE), c.next));
        }
    }

    pub fn network_changed(&mut self, now: Date) {
        self.changed_at = Some(now);
        let in_window = self.woke_at.is_some_and(|w| now.time_interval_since(w) <= WAKE_WINDOW);
        if self.survivors_pending && in_window {
            self.survivors_at = Some(now.adding(SETTLE));
        }
        for c in self.candidates.values_mut().filter(|c| !c.attempting) {
            c.next = Some(now.adding(SETTLE));
        }
    }

    /// A connected connection was found down (`ConnectionEvent::Dropped`), with its log's category.
    pub fn dropped(&mut self, key: &str, name: &str, now: Date, kind: FailureKind) {
        if self.user_off.contains(key) || !kind.worth_retrying() || self.candidates.contains_key(key) {
            return;
        }
        let within = |at: Option<Date>, window: f64| at.is_some_and(|t| now.time_interval_since(t) <= window);
        let after_wake = self.up_at_sleep.contains(key) && within(self.woke_at, WAKE_WINDOW);
        let network = self.network_down || within(self.changed_at, NETWORK_WINDOW);
        if after_wake || network {
            self.candidates.insert(
                key.to_string(),
                Candidate { name: name.to_string(), attempts: 0, next: Some(now.adding(SETTLE)), attempting: false },
            );
        }
    }

    /// Our attempt failed (`ConnectionEvent::Failed` while [`Self::is_attempting`]).
    pub fn failed(&mut self, key: &str, now: Date, kind: FailureKind) -> Vec<Action> {
        let Some(c) = self.candidates.get_mut(key).filter(|c| c.attempting) else { return Vec::new() };
        c.attempting = false;
        if kind.worth_retrying() && c.attempts <= RETRY_DELAYS.len() {
            c.next = Some(now.adding(RETRY_DELAYS[c.attempts - 1]));
            return Vec::new();
        }
        let c = self.candidates.remove(key).expect("present");
        vec![Action::Notify(Notice::ReconnectFailed { key: key.to_string(), name: c.name, reason: plain(kind) })]
    }

    pub fn survivors_due(&self, now: Date) -> bool {
        self.survivors_pending && self.survivors_at.is_some_and(|t| now.time_interval_since(t) >= 0.0)
    }

    /// Once per wake: the connections up before the sleep and still connected (`connected`) whose network is
    /// directly reachable now are disconnected, with a notice; the others stay. No network: wait for a change.
    pub fn survivors(&mut self, now: Date, snapshot: &NetworkSnapshot, connected: &[String]) -> Vec<Action> {
        let _ = now;
        if !snapshot.has_network() {
            self.survivors_at = None;
            return Vec::new();
        }
        self.survivors_pending = false;
        self.survivors_at = None;
        let mut actions = Vec::new();
        for key in connected.iter().filter(|k| self.up_at_sleep.contains(*k)) {
            let empty = VpnNetworks::default();
            if let Some(why) = surviving_check(snapshot, self.networks.get(key).unwrap_or(&empty)) {
                self.user_off.insert(key.clone());
                self.candidates.remove(key);
                actions.push(Action::Disconnect(key.clone()));
                actions.push(Action::Notify(Notice::DisconnectedHere { key: key.clone(), why }));
            }
        }
        actions
    }

    pub fn is_attempting(&self, key: &str) -> bool {
        self.candidates.get(key).is_some_and(|c| c.attempting)
    }

    /// Something is due to be evaluated (the driver then probes the network and calls [`Self::evaluate`]).
    pub fn due(&self, now: Date) -> bool {
        self.candidates.values().any(|c| !c.attempting && c.next.is_some_and(|t| now.time_interval_since(t) >= 0.0))
    }

    pub fn evaluate(
        &mut self,
        now: Date,
        snapshot: &NetworkSnapshot,
        enabled: &dyn Fn(&str) -> bool,
        locked: bool,
    ) -> Vec<Action> {
        self.network_down = !snapshot.has_network();
        let due: Vec<String> = self
            .candidates
            .iter()
            .filter(|(_, c)| !c.attempting && c.next.is_some_and(|t| now.time_interval_since(t) >= 0.0))
            .map(|(k, _)| k.clone())
            .collect();
        let mut actions = Vec::new();
        for key in due {
            if !enabled(&key) {
                self.candidates.remove(&key);
                continue;
            }
            let decision = if locked {
                Decision::Skip(Skip::VaultLocked)
            } else {
                let empty = VpnNetworks::default();
                decide(self.fingerprints.get(&key), snapshot, self.networks.get(&key).unwrap_or(&empty))
            };
            let c = self.candidates.get_mut(&key).expect("due");
            match decision {
                Decision::Reconnect => {
                    c.attempts += 1;
                    c.attempting = true;
                    actions.push(Action::Connect(key));
                }
                Decision::Wait => c.next = None,
                Decision::Skip(why) => {
                    let name = c.name.clone();
                    self.candidates.remove(&key);
                    actions.push(Action::Notify(Notice::NotReconnected { key, name, why }));
                }
            }
        }
        actions
    }
}

//! Auto-reconnect's driver (maintainer decision 4): one thread owns the `Planner`, receives the events (connect
//! started, connected, dropped, failed, user disconnect, sleep, wake, network change), probes the physical network
//! when something is due, and runs the planner's actions (a connect, a notice). Probes and connects never run on
//! the manager's, the main or a hook's thread. No OS `cfg`: the OS is behind `Platform::network()` and the
//! lifecycle.

use macvpn_app_core::failure_reason::FailureKind;
use macvpn_app_core::reconnect::{self, Action, Planner, fingerprint};

use macvpn_core::date::Date;
use macvpn_core::models::{ConnectionState, parse_uuid};

pub enum Event {
    Started(String),
    Connected(String),
    Dropped(String, String),
    Failed(String),
    UserDisconnected(String),
    Forget(String),
    Sleep,
    Wake(Vec<String>),
    NetworkChanged,
}

pub struct Reconnect {
    tx: Mutex<Sender<Event>>,
    planner: Arc<Mutex<Planner>>,
}

impl Reconnect {
    pub fn send(&self, e: Event) {
        let _ = self.tx.lock().unwrap_or_else(PoisonError::into_inner).send(e);
    }

    pub fn is_attempting(&self, key: &str) -> bool {
        self.planner.lock().unwrap_or_else(PoisonError::into_inner).is_attempting(key)
    }
}

fn connected_keys(state: &AppState) -> Vec<String> {
    state.manager.states().into_iter().filter(|(_, s)| s.is_connected()).map(|(k, _)| k).collect()
}

fn snapshot(state: &AppState) -> Option<macvpn_platform_api::NetworkSnapshot> {
    if state.env.sandbox {
        return crate::platform::smoke_network(state); // debug smoke only; `None` otherwise
    }
    crate::platform::get().network().snapshot().ok()
}

/// The VPN's networks: its stored config, plus OpenVPN's PUSH_REPLY from the current log.
fn networks(state: &AppState, key: &str) -> VpnNetworks {
    let Some(ConnectionItem::Managed(c)) = state.manager.item(key) else { return VpnNetworks::default() };
    let config = state.connections_store().load_config_wiped(&c.id).map(|z| z.to_string()).unwrap_or_default();
    let mut n = VpnNetworks::from_config(c.kind, &config);
    if let Some(source) = state.helper.log_source(&c.id) {
        n.add_pushed(&macvpn_core::log::LogTailer::with_source(source).read_new());
    }
    n
}

pub fn start(state: &Arc<AppState>) -> Arc<Reconnect> {
    let (tx, rx) = channel();
    let r = Arc::new(Reconnect { tx: Mutex::new(tx), planner: Arc::new(Mutex::new(Planner::default())) });
    let (driver, s) = (r.clone(), state.clone());
    std::thread::Builder::new().name("macvpn-reconnect".into()).spawn(move || run(&s, &driver, &rx)).expect("reconnect thread");
    r
}

fn run(state: &Arc<AppState>, r: &Reconnect, rx: &Receiver<Event>) {
    loop {
        match rx.recv_timeout(Duration::from_secs(1)) {
            Ok(e) => handle(state, r, e),
            Err(std::sync::mpsc::RecvTimeoutError::Timeout) => {}
            Err(_) => return,
        }
        let now = Date::now();
        if r.planner.lock().unwrap_or_else(PoisonError::into_inner).survivors_due(now)
            && let Some(snap) = snapshot(state)
        {
            let connected = connected_keys(state);
            let actions = r.planner.lock().unwrap_or_else(PoisonError::into_inner).survivors(now, &snap, &connected);
            actions.into_iter().for_each(|a| act(state, a));
        }
        if !r.planner.lock().unwrap_or_else(PoisonError::into_inner).due(now) {
            continue;
        }
        let Some(snap) = snapshot(state) else { continue };
        let prefs = state.prefs.clone();
        let enabled = move |key: &str| parse_uuid(key).is_some_and(|u| reconnect::is_enabled(prefs.as_ref(), &u));
        let actions = r.planner.lock().unwrap_or_else(PoisonError::into_inner).evaluate(now, &snap, &enabled, state.manager.is_locked());
        for a in actions {
            act(state, a);
        }
    }
}

fn handle(state: &Arc<AppState>, r: &Reconnect, e: Event) {
    let now = Date::now();
    let p = || r.planner.lock().unwrap_or_else(PoisonError::into_inner);
    match e {
        Event::Started(key) => {
            let ours = p().is_attempting(&key);
            let fp = if ours { None } else { snapshot(state).as_ref().and_then(fingerprint) };
            p().connect_started(&key, fp, ours);
        }
        Event::Connected(key) => {
            let n = networks(state, &key);
            p().connected(&key, n);
        }
        Event::Dropped(key, name) => {
            let kind = crate::notifications::classify(state, &key);
            p().dropped(&key, &name, now, kind);
        }
        Event::Failed(key) => {
            let kind = crate::notifications::classify(state, &key);
            let actions = p().failed(&key, now, kind);
            actions.into_iter().for_each(|a| act(state, a));
        }
        Event::UserDisconnected(key) => p().user_disconnected(&key),
        Event::Forget(key) => p().forget(&key),
        Event::Sleep => {
            let fp = snapshot(state).as_ref().and_then(fingerprint);
            p().sleep(&connected_keys(state), fp);
        }
        Event::Wake(connected) => p().wake(now, &connected),
        Event::NetworkChanged => p().network_changed(now),
    }
}

fn act(state: &Arc<AppState>, action: Action) {
    match action {
        Action::Notify(n) => crate::notifications::notice(state, &n),
        Action::Disconnect(key) => {
            let Some(ConnectionItem::Managed(c)) = state.manager.item(&key) else { return };
            let manager = state.manager.clone();
            // As the user's: leases on it end, and the user-disconnect rule keeps it down.
            std::thread::spawn(move || manager.disconnect_for(&c, macvpn_app_core::DisconnectCause::User));
        }
        Action::Connect(key) => {
            let Some(ConnectionItem::Managed(c)) = state.manager.item(&key) else { return };
            state.notices.lock().unwrap_or_else(PoisonError::into_inner).mark_auto(&key);
            let manager = state.manager.clone();
            std::thread::spawn(move || manager.connect(&c, false));
        }
    }
}

/// The hooks (from `connect_hooks` and the setup hook).
pub fn wire(state: &Arc<AppState>, r: &Arc<Reconnect>) {
    let rr = r.clone();
    let last: Mutex<std::collections::HashMap<String, ConnectionState>> = Mutex::default();
    state.manager.add_state_listener(move |key, s| {
        let previous = last.lock().unwrap_or_else(PoisonError::into_inner).insert(key.to_string(), s.clone());
        let was_idle = !previous.as_ref().is_some_and(ConnectionState::is_active);
        if was_idle && matches!(s, ConnectionState::Connecting) {
            rr.send(Event::Started(key.to_string()));
        }
        if matches!(s, ConnectionState::Connected { .. }) && !previous.as_ref().is_some_and(ConnectionState::is_connected) {
            rr.send(Event::Connected(key.to_string()));
        }
    });
    let rr = r.clone();
    state.manager.add_user_disconnect_listener(move |key| rr.send(Event::UserDisconnected(key.to_string())));
}

    }
}

## Risks

- **SSID visibility.** macOS 14.4+ (`ipconfig getsummary` shows `<redacted>`) and Windows 11 24H2 (`WlanQueryInterface` needs location permission) hide the SSID from the app. The gateway's MAC then decides: two networks behind the same router model in the same building differ in MAC; a mobile hotspot that keeps its MAC across places would look the same (reconnect allowed — still guarded by the reachability check). Asking for location permission would change the bundle (Info.plist, MSI) and alarm users; not done.
- **Gateway MAC right after wake.** ARP/NDP may not be resolved yet: the probe primes ARP (macOS) or resolves actively (Windows), and a missing MAC fails closed ("could not be identified"). A false "not reconnected" is the safe error; Task 14's checklist watches for it.
- **Pushed routes need OpenVPN's log at verbosity 3+.** With `verb 1`/`2` or a server that pushes routes after a later `PUSH_UPDATE`, only the config's routes are known; the reachability check can then miss a pushed office subnet and reconnect at the office (the tunnel would route the local subnet). The guide says to keep the default `verb 3`; a later improvement could read the routing table while connected.
- **No prefixes for IKEv2/strongSwan, SSTP and native kinds** (their routes are negotiated): only the fingerprint check guards them.
- **Surviving tunnels** (OpenVPN `ping-restart`, WireGuard) are disconnected after wake only when the VPN's network is directly reachable; on another network they stay up (maintainer's decision). The check depends on the known prefixes, so the "pushed routes need verb 3" and "no prefixes for IKEv2/SSTP/native" limits apply to it too; and it runs only after a wake, not after a network change without sleep (an Ethernet cable plugged in at the office while connected is not detected).
- **Windows Modern Standby** may deliver no suspend/resume to a desktop app even with `RegisterSuspendResumeNotification`; the network watch (the Wi-Fi reconnecting) then drives the planner, and "up before sleep" falls back to the states seen at the first network change only through the network-loss rule (a drop within 60 s of the change).
- **Notification volume:** "connected" on every connect may feel noisy; the switch is global. A per-kind choice is not planned.
- **Toast clicks after 32 newer toasts or a restart** do nothing (existing limit of `win/toast.rs`), now more likely because more toasts are posted. A COM activator would fix it; out of scope.
- **Theme on Windows dialogs:** the COM file dialogs, message boxes and UAC follow Windows' theme, not the app's; WebView2's scrollbars follow `PreferredColorScheme` only on recent runtimes.
- **Classification by substrings** may mis-file an unusual log line; the result is only the notification body's sentence (never a decision except "do not retry" for `AuthFailed`/`CertificateProblem`, whose patterns are specific).
