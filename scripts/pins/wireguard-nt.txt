# key below) under "Sectigo Public Code Signing Root R46". Pinned: the issuing CA's key, so a renewed leaf from the
# same CA needs no change. When WireGuard LLC changes CA, a downloaded DLL is refused (the service log says
# "… not under a pinned CA …") and the bundled DLL stays in use until a WinVPN release adds the new CA's key here:
